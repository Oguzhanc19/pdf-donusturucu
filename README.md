## 🚀 Özellikler

### 📄 PDF ve Dosya İşlemleri (15 Araç)

| Araç | Açıklama |
|------|----------|
| Word → PDF | Word dosyasını PDF'e dönüştürür |
| Excel → PDF | Excel dosyasını PDF'e dönüştürür |
| PowerPoint → PDF | Sunum dosyasını PDF'e dönüştürür |
| **PNG/JPG → PDF** | Resimleri tek PDF'te birleştirir |
| PDF → Word | PDF'ten metin çıkarır |
| PDF → JPG | PDF sayfalarını resme dönüştürür |
| **PDF Birleştirme** | Birden fazla PDF'i birleştirir |
| PDF Bölme | PDF'i sayfa aralığına göre böler |
| PDF Sıkıştırma | PDF dosya boyutunu küçültür |
| PDF Şifreleme | PDF'e şifre koyar |
| PDF Şifre Kaldırma | Şifreli PDF'i açar |
| PDF Sayfa Döndürme | Sayfaları 90°/180°/270° döndürür |
| PDF Sayfa Silme | İstenmeyen sayfaları siler |
| PDF Filigran Ekleme | Tüm sayfalara filigran ekler |
| PDF'ten Metin Çekme | PDF'ten metin çıkarır (OCR) |

### 🎥 Video İşlemleri (8 Araç)

| Araç | Açıklama |
|------|----------|
| URL'den Video İndirme | URL ile video indir (yt-dlp) |
| URL'den Ses İndirme | URL'den MP3 olarak ses indir |
| Video Format Dönüştürme | MP4, WEBM, AVI arası dönüşüm |
| Video Sıkıştırma | Video boyutunu küçültür |
| Videodan Ses Ayırma | Videodan ses dosyasını çıkarır |
| Videodan Ekran Görüntüsü | İstediğiniz kareden screenshot alır |
| Video Birleştirme | Birden fazla videoyu birleştirir |
| Video Kırpma | Videonun belirli bölümünü keser |

### 🖼️ Resim İşlemleri (10 Araç)

| Araç | Açıklama |
|------|----------|
| **Arka Plan Kaldırma** | Resim arka planını şeffaf yapar |
| **Resim Sıkıştırma** | Kalite ayarlı sıkıştırma |
| JPG ↔ PNG | Format dönüşümü |
| WEBP ↔ PNG | Format dönüşümü |
| Resim Yeniden Boyutlandırma | Pixel bazlı boyut değiştirme |
| Toplu Resim İşleme | Birden fazla resmi toplu işler |
| Resim Döndürme | 90°, 180°, 270°, yatay/dikey çevir |
| Filigran Ekleme | Resme metin filigranı ekler |
| **QR Kod Oluşturma** | Metin veya URL'den QR kod üretir |
| Barkod Oluşturma | Code 128 / Code 39 barkod üretir |

## 🛠️ Kullanılan Teknolojiler

| Teknoloji | Kullanım Alanı |
|-----------|---------------|
| **HTML/CSS/JS** | Temel yapı |
| **[pdf-lib](https://pdf-lib.js.org/)** | PDF işlemleri (birleştirme, bölme, döndürme, filigran vb.) |
| **[jsPDF](https://github.com/parallax/jsPDF)** | Resimden PDF oluşturma |
| **Canvas API** | Resim işlemleri (sıkıştırma, döndürme, format dönüşüm) |
| **MediaRecorder API** | Video sıkıştırma, format dönüşüm, kırpma |
| **Web Audio API** | Videodan ses ayırma |
| **PWA** | Offline çalışma, ana ekrana ekleme |

## 📱 Kurulum

### 🌐 Web'den Kullanım (Önerilen)

Doğrudan tarayıcıdan açın:

👉 **https://oguzhanc19.github.io/pdf-donusturucu/**

Telefonunuzda **"Ana Ekrana Ekle"** butonuna tıklayarak uygulama gibi kullanabilirsiniz.

### 💻 Yerel Kullanım

```bash
# 1. Repoyu klonlayın
git clone https://github.com/Oguzhanc19/pdf-donusturucu.git
cd pdf-donusturucu

# 2. Sunucuyu başlatın
python sunucu.py

# 3. Tarayıcıda açın
# http://localhost:8080
```

> 📱 **Telefon ile**: Bilgisayar ve telefon aynı WiFi ağındaysa, sunucu ekranında gösterilen IP adresini telefonunuzun tarayıcısına yazın.

## 📂 Proje Yapısı

```
pdf-donusturucu/
├── index.html          # Ana sayfa
├── style.css           # Stiller (koyu tema)
├── app.js              # Ana uygulama (40+ araç)
├── jspdf.umd.min.js    # jsPDF kütüphanesi
├── pdf-lib.min.js      # pdf-lib kütüphanesi
├── mammoth.min.js      # Word okuma kütüphanesi
├── manifest.json       # PWA manifest
├── sw.js               # Service Worker (offline)
├── icon-512.png        # Uygulama ikonu
├── sunucu.py           # Yerel ağ sunucusu
└── MOBIL_BASLAT.bat    # Windows hızlı başlatma
```

## ⚡ Hızlı Başlangıç

1. Siteyi açın veya yerel sunucuyu başlatın
2. Ana ekrandan istediğiniz aracı seçin veya arama yapın
3. Dosyanızı yükleyin veya metninizi girin
4. İşlemi başlatın ve sonucu indirin

## 🔒 Gizlilik

- ✅ Tüm işlemler **tarayıcınızda** gerçekleşir
- ✅ Dosyalarınız **hiçbir sunucuya yüklenmez**
- ✅ İnternet bağlantısı olmadan da çalışır (PWA)
- ✅ Açık kaynak — kodları inceleyebilirsiniz

> ⚠️ Video indirme ve Office dönüşümleri gibi bazı işlemler sunucu tarafı araçlar (FFmpeg, yt-dlp) gerektirir. Bu araçlar için uygulama bilgilendirme ve masaüstü komut önerileri sunar.
