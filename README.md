## 🇬🇧 English

A highly sophisticated **Progressive Web App (PWA)** that brings heavy-duty document conversion natively into the browser. By processing files entirely on the client side, it guarantees zero data leakage, making it perfect for handling sensitive documents.

### 🧠 Core Architecture
- **`mammoth.js` Integration**: Used for parsing `.docx` files natively in JS. Instead of complex server-side LibreOffice conversions, Mammoth translates Word documents into semantic HTML cleanly in the browser.
- **`pdf-lib` & `jsPDF`**: These powerful engines take the semantic HTML generated by Mammoth (or user inputs) and programmatically draw PDF documents, complete with embedded fonts and custom metadata.
- **Service Worker Caching**: The `sw.js` file caches the heavy library files (`pdf-lib.min.js`, `mammoth.min.js`) upon first load. This ensures the app can convert documents instantly even when the user goes completely offline.

## 🇹🇷 Türkçe

Ağır belge dönüştürme işlemlerini uzak bir sunucu (server) yerine doğrudan tarayıcı içerisine (Client-Side) getiren oldukça gelişmiş bir **Progresif Web Uygulaması (PWA)**. Belgeler cihaz dışına çıkmadığı için %100 veri gizliliği garanti eder ve hassas dokümanlar için idealdir.

### 🧠 Çekirdek Mimari
- **`mammoth.js` Entegrasyonu**: `.docx` uzantılı Word dosyalarını tarayıcı içinde okumak için kullanılır. Sunucu tarafındaki hantal dönüştürücüler yerine, Mammoth, Word belgelerini tamamen tarayıcıda temiz ve anlamsal HTML'e (semantic HTML) çevirir.
- **`pdf-lib` & `jsPDF`**: Mammoth tarafından oluşturulan HTML verisini (veya kullanıcı girişlerini) alarak piksellerine kadar programlanabilir PDF dosyaları çizer. Özel fontları ve PDF meta verilerini işleyebilir.
- **Service Worker Önbellekleme**: `sw.js` dosyası, uygulamanın kullandığı ağır kütüphaneleri (`pdf-lib.min.js`, `mammoth.min.js`) ilk açılışta önbelleğe alır. Bu sayede cihaz internet bağlantısını tamamen kaybetse bile çevrimdışı belge dönüştürmeye devam edebilir.
