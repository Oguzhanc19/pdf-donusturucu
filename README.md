## 🇬🇧 English
A powerful **Progressive Web App (PWA)** that brings PDF manipulation right into your browser. Without relying on any external server, this tool uses cutting-edge JS libraries to convert, read, and edit document files securely on your local device.

### ✨ Key Features
- 🚀 **Client-Side Processing**: 100% privacy! All files are processed locally using `pdf-lib` and `jspdf`.
- 🔄 **Document Conversion**: Integrates `mammoth.js` to convert Word documents to clean web formats or PDFs.
- 📱 **Installable**: Full PWA support—install it on your phone or PC and use it offline.

## 🇹🇷 Türkçe
PDF düzenleme işlemlerini doğrudan tarayıcınıza getiren güçlü bir **Progresif Web Uygulaması (PWA)**. Herhangi bir uzak sunucuya ihtiyaç duymadan, belgelerinizi kendi cihazınızda güvenli bir şekilde dönüştürmek, okumak ve düzenlemek için modern JS kütüphanelerini kullanır.

### ✨ Temel Özellikler
- 🚀 **İstemci Tarafında İşlem**: %100 Gizlilik! Tüm dosyalar `pdf-lib` ve `jspdf` kullanılarak tamamen lokal ortamda işlenir.
- 🔄 **Belge Dönüştürme**: Word belgelerini temiz web formatlarına veya PDF'ye dönüştürmek için `mammoth.js` entegrasyonu.
- 📱 **Yüklenebilir Uygulama**: Tam PWA desteği sayesinde telefonunuza veya bilgisayarınıza yükleyip internetsiz kullanabilirsiniz.
