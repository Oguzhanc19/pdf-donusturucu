# PDF Converter (PDF Dönüştürücü)

## English
A web-based tool to convert and manipulate PDF files. Built as a Progressive Web Application (PWA), it utilizes powerful JavaScript libraries like `pdf-lib` and `mammoth.js` to process documents directly in the browser without server-side processing.

### Features
- In-browser PDF manipulation.
- PWA support (offline access and installation).
- Document parsing and conversion.

---

## Türkçe
PDF dosyalarını dönüştürmek ve düzenlemek için web tabanlı bir araç. Progresif Web Uygulaması (PWA) olarak tasarlanmış olup, `pdf-lib` ve `mammoth.js` gibi güçlü JavaScript kütüphanelerini kullanarak belgeleri sunucuya ihtiyaç duymadan doğrudan tarayıcı üzerinde işler.

### Özellikler
- Tarayıcı içi PDF düzenleme.
- PWA desteği (çevrimdışı erişim ve yüklenebilirlik).
- Belge dönüştürme ve okuma.
